# Beginner clarity standard

Apply this standard to every future product milestone, including stock research,
portfolio planning and rental analysis. Preserve the financial meaning while
making the first view concise. This is a design requirement, not a claim that
the whole application has passed novice usability testing.

- Lead with the question the page answers and the next useful action.
- Use familiar labels. Introduce an abbreviation with its meaning, not alone.
- Put currency, percentage basis, relevant dates and comparison basis beside the
  number or in immediately available help. Separate observation, report,
  publication and download dates.
- Give each chart a clear question, labelled units, useful hover values and one
  short reading hint. Distinguish historical observations from projections.
- Separate business results, data availability and investment readiness. Missing
  evidence is not poor company performance; passing a rule is not a buy signal.
- Show the key conclusion first. Put formulas, source metadata and detailed
  limitations in optional help, popovers or expanders, without hiding a limitation
  that would change how someone interprets the conclusion.
- Use a small numerical example to teach a difficult term. Do not show the entire
  glossary at once. Do not imply yields, volatility or past results promise returns.
- Use text with any status color. Check card wrapping, chart boundaries, labels,
  hover content and keyboard-labelled controls in the running application.
- Prefer useful visual structure over decorative charts: short step guides,
  evidence status cards, date timelines, side-by-side comparisons and annotated
  examples. Avoid adding another visual if it repeats the same information.

## Current application

The stock Research screen now has an optional one-term guide with examples,
plain-language status labels, separate business/price/history cards and concise
valuation explanations. Exact evidence and retrieval details remain available.
Scores, filters, underlying values and verification gates are unchanged.

Remaining work: apply the same review to company details, portfolio/decision
screens, goal planning and rentals as their milestones are completed. A real
novice task walkthrough is still needed; automated tests and visual inspection
do not establish that a beginner understands the product.

# Five-minute synthetic demonstration

Use a clean clone with session-only defaults and no provider credentials. Use
fictional inputs throughout; no personal financial file or real account is needed.

1. Start Streamlit and the local API as described in the README.
2. Choose **Goals**. Change a contribution or deadline and inspect how the
   required contribution changes. Explain that return assumptions are inputs,
   not promises. Inspect the year-by-year table.
3. Choose **Tools → Contribution allocator**. Use the example allocation to
   inspect integer-dollar/cent accounting and concentration limits. This is a
   contribution-only optimization problem, not a return optimizer.
4. Choose **Tools → Research workbench → Synthetic stock strategy**. Inspect
   the fictional companies, eligibility findings, score contributions and sector
   constraints. Show that an infeasible case withholds a complete proposal.
5. Choose **Real estate** or **Tools → Rental property**. Inspect the supplied
   scenario assumptions and cash flows. Explain that a manually entered rent
   does not establish the rent achievable for a real property.

Real stock evidence is deliberately absent from the public source package.
Selecting the real-data research view may show withheld/unavailable evidence;
that is expected in a clean clone. The source-refresh/evaluation documentation
describes the separately configured local research edition.

For a research-lab discussion, explain one independently checked calculation,
one failure-preservation test and the UTC/local freshness bug with its boundary
tests. Discuss limitations and the next validation experiment. Do not describe
synthetic examples or software test counts as investment-performance results.
